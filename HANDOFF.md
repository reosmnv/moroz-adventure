## Ассеты героини (готово, проверено глазами)
- `assets/sprites/<prime|ultimate>/<анимация>-<east|west>.png`: полосы кадров 128x128, ступни y=112, центр корпуса x=64. `assets/sprites/anims.json`: кадры, fps, loop, hit/hits, pre.
- Prime: idle, walk, dash, jab, cross, teep, superman (B), highkick (A B), uppercut (A A B), hurt, fall, getup, transform-up.
- Ultimate: idle, walk, dash, elbow, knee, roundhouse, spin-elbow (B), flying-knee (A B), hurricane (A A B, 3 попадания), hurt, fall, getup, transform-down.
- Просмотр: `python3 -m http.server 8090 --bind 100.118.72.60` из папки проекта, затем http://100.118.72.60:8090/anim-preview/ ; GIF в `assets/sprites/gif/`.
- Пересборка: `python3 tools/sprites.py fetch && python3 tools/sprites.py build && python3 tools/gifs.py`. Чистка кадров через `DROP`, попадания `HIT/HITS`, переходы `<name>-pre` в `tools/sprites.py`.
- PixelLab id: Prime `8f079407-9eb2-48f9-9b07-695c53169e9f`, Ultimate `fda7726a-5a4b-45df-b0e9-5e5adadc9540` (имя в PixelLab «Nasty Moroz», переименовать вручную).
