# birthday-coop: правила проекта

Кооп-битэмап ко дню рождения Анастасии. Жёсткого срока нет (дедлайн 07.11 снят mr.R 06.11): качество важнее скорости, объём не режем ради даты.
Перед работой прочитай `HANDOFF.md` (текущее состояние и следующий шаг) и нужный раздел `SPEC.md`.

## Схема работы (одна, действует с 07.11)
- Claude ведущий: режет работу на пачки, пишет ТЗ (`tasks/TZ-NN-*.md`), принимает (diff, тесты, сеть, браузер), коммитит принятое в ветку `tz-NN`. Решения принимает mr.R.
- Codex исполнитель: пишет код по ТЗ, запускает его Claude-оркестратор (`codex exec`, команда в `CODEX-LEAD.md`). Правила для Codex: `AGENTS.md`.
- Генерации ассетов (PixelLab и др.) делает Claude.
- Мерж в `main`, пуш и рестарт боевого сервиса только по просьбе mr.R.

## Решения PO (не пересматривать без запроса)
- wss через бесплатный `<ip>.sslip.io` + Caddy. Домен не покупать, резервный хостнейм не нужен.
- Офлайн-соло (M-1) через общую симуляцию `shared/sim`. Точка решения о срезе 26.10.2026.
- Генератор спрайтов: PixelLab (выбран 23.10). Генерации PixelLab не экономить и цену не спрашивать; работа по ../PIXELLAB.md.
- Прочие платные генерации (Genex и др.) только после названной цены и согласия.

## Архитектура (держать)
- `shared/src/sim.ts`: вся логика боя. Чистые функции, без Phaser и Colyseus, случайность только через `world.seed`.
- `server/`: Colyseus 0.18 (`colyseus`, `@colyseus/schema` 5). Комната копирует мир в Schema, события шлёт `broadcast('ev')`. Поле `inputs` в Room зарезервировано Colyseus, не использовать.
- `client/`: Phaser 4.2 + Vite. Сцена знает только снимки и события из `GameSession`; веток `if (online)` в рендере нет. Офлайн = `LocalSession`, онлайн = `OnlineSession`.
- UI-элементы сцены с `setScrollFactor(0)` и позицией от `this.scale.width`: ширина игры меняется под экран, высота фиксирована 270.

## Конец сессии
Обнови `HANDOFF.md` (коротко: текущее состояние, следующий шаг, открытые вопросы), ход работ и детали дописывай в `HANDOFF-archive.md`. Если менялись `shared/` или `server/`, перед этим прогони `npm run test:net`.

## Команды
- `ops/dev.sh` перезапуск сервера (:2567) и клиента (:5173) на Tailscale-IP 100.118.72.60. Убивает процессы сервера без проверки порта: при живом боевом (systemd `birthday-coop`, :2567) НЕ запускать. Для проверок свой сервер: `HOST=127.0.0.1 PORT=2568 node --import tsx server/src/index.ts`.
- `npm run test:net` сетевые сценарии ботами. Гонять после любых правок `shared/` и `server/`; все проверки должны быть OK.
- `npm run test:sim` сценарии боя Анастасии на `shared/sim` без сервера (гонять после правок sim и `hero-data`).
- `python3 tools/gen_anims_ts.py` после пересборки спрайтов: обновляет `shared/src/anims-data.ts` и копирует полосы в `client/public/sprites/`.
- `npx tsc -p tsconfig.json` проверка типов всего проекта.

## Грабли
- Не убивать процессы через `pkill -f` с шаблоном: убивает собственный shell. Останавливать по PID.
- Playwright работает импортом по абсолютному пути `/home/agent/node_modules/playwright/index.mjs` (пример `scratchpad/tz22b-main.mjs`: свой vite dev-порт, 844x390). `npx playwright` не использовать. В песочнице Codex браузер и сеть недоступны: их прогоняет Claude.
- По http (tailnet) Safari не даёт `navigator.share` и clipboard: не полагаться на них без запасного пути.
- Тихий зацикленный `<audio>` вешает Safari. Для беззвучного режима только `navigator.audioSession.type = 'playback'`.
- sudo: пароль в `~/.secrets/sudo`, вызывать `sudo -S -p '' <команда> < ~/.secrets/sudo` (разрешено mr.R 24.10). Пароль не печатать и не коммитить.

## Общение с mr.R
Общий стиль общения в `~/.claude/CLAUDE.md`, здесь только специфика проекта. Звук и iPhone проверяет только он: не писать «работает на iPhone», если он не подтвердил. Коммит принятой пачки в ветку `tz-NN` делает Claude; мерж в `main`, пуш и рестарт сервиса только по его просьбе.
