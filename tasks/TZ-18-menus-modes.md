# TZ-18: главное меню, Новая игра / Тест-режим, настройки, пауза, смена героя

Цель: у игры появляются базовые сценарии. «Новая игра» = полноценное прохождение без тест-кнопок. «Тест-режим» = выбор локации и тест-инструменты. Настройки, полноценная пауза, смена героя посреди игры офлайн и онлайн. Единый пиксельный стиль всех экранов.

Работа идёт **двумя параллельными задачами** в разных копиях репозитория:
- **18A (ядро)**: `shared/`, `server/`. Ветка `tz-18a`.
- **18B (интерфейс)**: `client/`. Ветка `tz-18b`.
Файлы другой части не трогай. Контракт между частями ниже: 18A его реализует, 18B на него опирается. Если в 18B tsc ругается только на отсутствие экспортов контракта из `@bc/shared`, это ожидаемо: перечисли такие ошибки в отчёте.

## Контракт (общий для 18A и 18B)
`shared` экспортирует:
- `TEST_TOOLS` остаётся и теперь значит «тест-режим доступен в меню» (релизный выключатель). Его значение не менять.
- `createWorld(seed, testTools, level, stage)` как сейчас; `world.testTools` = режим этой игры.
- `switchHero(w: World, id: string, char: string): boolean` — сменить героя игрока; false, если нельзя (нет игрока, неизвестный или занятый другим герой, тот же герой, идёт переход/кинематика).
- `testHeal(w: World): void` — всем игрокам полное HP, поднять лежащих. Работает только при `w.testTools`.
- `testGod(w: World, id: string, on: boolean): void` — бессмертие игрока (урон не проходит). Только при `w.testTools`. Поле игрока `god?: boolean` попадает в снимок.
- `testKillAll(w: World): void` — все текущие враги, кроме боссов, умирают как от удара (счёт встречи идёт обычным путём); боссу 1 HP. Только при `w.testTools`.
- `nextStage`, `spawnEnemies`, `chargeUlt` как сейчас, все три без эффекта при `!w.testTools`.

Сервер (`GameRoom`):
- `create('game', { level, stage, testMode })`: `testMode` булево, по умолчанию false; `stage` принимается только при `testMode`, иначе 0. При `TEST_TOOLS === false` testMode всегда false.
- В состоянии комнаты поле `testMode: boolean` (клиент, вошедший по ссылке или коду, берёт режим отсюда).
- Сообщения: `switch` (char) → `switchHero`, при отказе `client.send('pickError', 'Персонаж занят')`; тестовые `next`, `spawn`, `charge`, `heal`, `god` (boolean), `killall` — работают только при `world.testTools`.
- Если игрок, поставивший паузу, отключился или вышел, пауза снимается.

## 18A: ядро (`shared/`, `server/`)
- A1. `switchHero`: сохраняет id, позицию, направление, `connected`, `away`, HP в той же доле от максимума, заряд ульты. Сбрасывает всё боевое состояние героя (анимация/move, кулдауны, комбо и очереди, форма и таймеры ульты, неуязвимость, буря, рывки, прыжок, счётчики ударов, `wantBall`, всё `ramil`, `god` остаётся). Освобождает связи старого героя: враг в `held`/`thrown` от этого id отпускается стоя (без урона), снимаются `markedBy`, `burnBy`, `charmBy`, `pin.by` от этого id, отменяются `pending` с `owner` этого id (в том числе шар Kris), остановки врагов ультой этого игрока снимаются, `target`/боевой token врага на этом игроке освобождается. Событие `{ t: 'switch', id, char }` для клиента.
- A2. `testHeal`, `testGod`, `testKillAll` по контракту.
- A3. `GameRoom`: `testMode` из опций создания, поле состояния, сообщения из контракта, снятие паузы ушедшего. Начальный `world` в поле класса без `TEST_TOOLS` (режим false). Повторный `pick` по-прежнему запрещён, смена только через `switch`.
- A4. Тесты в `server/src/sim-test.ts`: смена героя в каждом из 4 направлений (12 пар) посреди атаки; Рамиль держит врага за горло → смена → враг свободен и стоит; Kris с летящим шаром → смена → шар не наносит урон от имени нового героя; занятый герой → false; тест-функции без `testTools` ничего не делают; `testKillAll` засчитывает встречу; `testGod` блокирует урон. В `test:net` (`server/src/net-test.ts` или где он лежит): комната с `testMode: true` видна второму клиенту как `testMode`, обычная комната отклоняет `spawn`/`next`/`charge`, `switch` работает и отклоняет занятого героя.

## 18B: интерфейс (`client/`)
Стиль: только текущая палитра CSS-переменных (`--ink --navy --deep --plum --mauve --lav --cream --pink --pink-dark --gold`), шрифт Press Start 2P, прямые углы, обводка `--px-outline`, кнопки как сейчас (основная розовая, второстепенная `--plum`). Никаких системных шрифтов и нативных чекбоксов. Исключение: карточка уведомления «Уведомление» в завязке остаётся в стиле госуслуг (это пародия). Минимальный размер текста 10px, кнопки не ниже 44px по высоте. Экран iPhone в горизонтали 844x390 и меньше (667x375): всё влезает без прокрутки.

- B1. **Главное меню** (`#menu`). Фон: `route/street.png`, растянут по высоте, `image-rendering: pixelated`, затемнён (`--deep` ~80%), поверх строки развёртки как у `.overlay`. Название крупно золотом: «НЕСУЩЕСТВУЮЩАЯ» (константа `GAME_TITLE` в `story.ts`), подзаголовок мелко «кооп на четверых». Ряд из 4 портретов героев (по 48px, pixelated) под названием. Кнопки столбцом:
  1. «Продолжить · КОД» — только если есть живой токен переподключения (`bc-reconnect`); возвращает в ту комнату.
  2. «Новая игра» (основная) → экран выбора: «С друзьями (онлайн)» / «Одна на телефоне (офлайн)» / «Назад». Новая игра всегда: stage 0, testMode false, с завязкой; удаляет старый токен.
  3. «Войти по коду» → поле кода + «Войти» + «Назад».
  4. «Тест-режим» (только при `TEST_TOOLS`) → экран: сетка 7 кнопок локаций (названия из карточек `route-data.ts`: Подъезд 3, Двор, «Беговая», Вагон, «Маяковская», Москва-Сити, Главный МФЦ), переключатель онлайн/офлайн пиксельными кнопками-вкладками, «Назад». Нажатие на локацию запускает тест.
  5. «Настройки».
  Если в адресе `#КОД`: первой кнопкой «Войти в комнату КОД». Чекбокс «Онлайн-режим» и строку «Сервер: …» с главного экрана убрать (адрес сервера показать мелко только в тест-режиме). `?stage=N` в адресе открывает экран тест-режима с подсвеченной локацией N. `<title>` = GAME_TITLE.
- B2. **Тест-режим в игре.** Тест-кнопки показываются по `testMode` сессии (офлайн из выбора меню, онлайн из состояния комнаты), не по `TEST_TOOLS`. Вместо ряда кнопок в `#topbar` одна кнопка «ТЕСТ», открывает выпадающую панель под ней: «Заряд ульты», «+3 врага», «Убить врагов», «Вылечить всех», «Бессмертие: вкл/выкл», «→ Локация». Панель закрывается повторным нажатием и не закрывает HUD, когда закрыта. В HUD при тест-режиме маленькая золотая метка «ТЕСТ». `GameSession` получает `testMode: boolean` и методы `heal()`, `god(on)`, `killAll()`, `switchHero(char)`.
- B3. **Пауза** (`#pauseBox`): «Продолжить», «Сменить героя», «Настройки», «Позвать друга» (онлайн; из topbar кнопку убрать), «В главное меню». Выход в меню: подтверждение «Выйти? Прогресс встречи пропадёт» (Да/Нет), затем `session.leave()`, удалить токен и перейти на чистый адрес без `#` и `?` (перезагрузка допустима). Онлайн-подпись «Паузу поставил друг» сохранить.
- B4. **Смена героя.** Экран выбора героя переиспользуется: свой текущий герой подписан «сейчас» и не нажимается, занятые другими заблокированы, есть «Назад». Выбор → `session.switchHero(char)`, при успехе возврат в паузу; ошибка «Персонаж занят» видна на экране. Сцена и HUD перерисовывают спрайт, портрет, иконки и цвет при смене `char` у того же id (событие `switch` и/или сравнение `char` в снимке). Офлайн `LocalSession` вызывает `switchHero` напрямую.
- B5. **Настройки** (из меню и из паузы, `client/src/settings.ts`, `localStorage` `bc-settings`): «Звук: вкл/выкл» (глушит `beep`), «Вспышки ударов: полные / мягкие / выкл» (мягкие = стоп-кадр и линии без инверсии; выкл = как `?fx=0`), «Тряска экрана: вкл/выкл» (все `cameras.main.shake`). Применяется сразу, без перезапуска. Каждая настройка: подпись слева, пиксельная кнопка-переключатель справа, «Назад».
- B6. **Сценарии без тупиков.** (а) Вся команда легла: поверх игры на 1,5 с пиксельный баннер «ЗАНОВО: БОЙ n/m» (по событию `restart`). (б) Финал «Ещё раз» → главное меню на чистом адресе. (в) Онлайн-связь потеряна и переподключение не удалось: оверлей «Связь потеряна» с «Переподключиться» и «В главное меню». (г) Повторная завязка: флаг `introSeen` сбрасывается при новой игре.
- B7. **Единый стиль текстовых экранов.** Вторая часть завязки (строки «Подъезд 3. Утро.…», кнопка «ПОГНАЛИ») и финал (`showFinale`) переводятся на Press Start 2P, палитру и кнопки игры; размер текста 12–16px, межстрочный 1.8. Конфетти финала в цветах палитры (`--lav --pink --gold`).
- B8. Убрать перекрытие «БОЙ n/m» тест-кнопками (решается B2).
