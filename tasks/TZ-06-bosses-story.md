## 3. Требования

R1. **Встреча с боссами.** `Encounter` получает необязательное поле `bosses?: BossId[]` (по очереди). Пропиши в `encounters.ts` (разовое исключение из «ведёт Claude»): вторая встреча `mayak` = `{ trigger: 1000, arena: [940, 1420], waves: [[vatnik R, vatnik L]], bosses: ['shaman', 'pizdulina'] }`. Волны идут как сейчас, затем выходит первый босс (с правого края арены), после его поражения пауза 1,5 с и выходит второй (событие `{ t: 'boss', id }` при каждом выходе). Встреча пройдена, когда побеждён последний босс и врагов нет. Чекпойнт (ТЗ-05 R7) при поражении во время боссов: заново с текущего босса (уже побеждённый не возвращается), волны не повторяются.

R2. **Босс в sim** — это `Enemy` с `boss: BossId`, `bossPhase: 1 | 2`, `atk?: string` (текущая атака). HP = `BOSS.hp × (duo ? DUO_HP_MULT : 1)`. Подход и разрешения как у grunt (босс занимает одно разрешение по своей цели; во время `ring`/`line`/`zones` занимает оба). Атака выбирается по кругу из списка фазы с учётом `cdMs` каждой (детерминированно, случайность только `world.seed`). Переход в фазу 2 при `hp ≤ phase2At × maxHp`: событие `{ t: 'phase', id }`, неуязвимость 1 с, текущая атака отменяется.
- `melee`: как grunt (замах, урон в первый тик active по `reach`/`depth` в сторону взгляда).
- `ring`: в `windup` событие `{ t: 'tele', id, shape: 'ring', x, y, r, ms }` (клиент рисует контур на полу); в `active` урон всем героиням в эллипсе `|dx| ≤ r`, `|dy| ≤ r*0.35`, отброс 60 от центра.
- `line`: телеграф `{ shape: 'line', x, y, h: halfH, dir, ms }`; в `active` урон героиням с `|y − y0| ≤ halfH` по стороне `dir` до края арены (один раз за атаку).
- `shots`: в `active` выпускает `count` снарядов с интервалом 100 мс по y ближайшей героини (y фиксируется при вылете), летят по x со `speed` до края арены, урон при `|dx| ≤ 10`, `|dy| ≤ 12`, снаряд исчезает. Снаряды в World (`shots[]`), в снимке и Schema (`x, y, dir`).
- `zones`: в `windup` выбирает `count` точек (под каждой героиней + случайные в арене), телеграф `{ shape: 'zone', x, y, r, ms: windupMs }`; в `active` зоны наносят `dmg` каждые 500 мс героиням внутри (`|dx| ≤ r`, `|dy| ≤ r*0.4`), в снимке `zones[]` (x, y, r, ms).
- `summon`: в `active` враги из списка появляются у краёв арены (не больше `MAX_ALIVE` вместе с боссом).
- Контроль по боссу: stun и charm игнорируются; freeze длится вдвое меньше; launch/air и pin не подбрасывают (урон проходит); `down` (сбивание) только отменяет текущий замах, не валит. Hurt-анимация без прерывания (броня как у tank). Отброс ×0,25.
- Поцелуй Нади по боссу: урона и ревности нет; если у босса есть `kissLine`, событие `{ t: 'taunt', id: <id босса>, line: kissLine }` (одно на поцелуй).
- Смерть босса: анимация `fall`, событие `{ t: 'bossDown', id }`, затем удаляется через 1,5 с.

R3. **Сеть и снимки.** `EnemyState`: + `boss: string`, `bossPhase: number`, `atk: string`. `GameState`: + `shots` (массив/map с x, y, dir), `zones` (x, y, r, ms). Снимок обеих сессий так же. События `boss`, `phase`, `tele`, `bossDown` по общему каналу.

R4. **Клиент: боссы.**
- Полоска HP босса вверху по центру (ширина 220, имя над ней шрифтом карточек, в фазе 2 полоса темнее и мигает имя 1 с).
- Телеграфы: `ring` = контур эллипса на полу (красный, alpha нарастает за `ms`), `line` = полупрозрачная красная полоса по y на всю арену в сторону `dir`, `zone` = красный круг на полу, в `active` заливка ярче. Под героями (depth пола).
- Снаряды `shots`: красная печать-кружок 10x10 с белой обводкой и словом «БАН» 5 px (или просто красный круг, если текст нечитаем).
- Босс без спрайта: прямоугольник 44x96 (shaman 0xd8d8d8, pizdulina 0x8b1e3f). Со спрайтом из `ENEMY_ANIMS[boss]`: те же правила, что для врагов (ТЗ-05 R9), плюс клип `cast` для `ring/line/shots/zones/summon` (держать последний кадр, пока идёт `windup`, затем проиграть до конца).
- При `boss` карточка по центру на 1,5 с: имя босса крупно (как карточки локаций).

R5. **Спрайты обычных врагов.** Клиент уже умеет рисовать по `ENEMY_ANIMS` (ТЗ-05 R9); проверь, что работает с реальными листами: Claude положит `client/public/sprites/enemies/<kind>/<clip>-east.png` и заполнит `ENEMY_ANIMS`.
