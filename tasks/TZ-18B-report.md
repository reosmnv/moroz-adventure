# Отчёт TZ-18B

Ветка: `tz-18b`. Реализована клиентская часть 18B. `shared/`, `server/`, `TEST_TOOLS`, ассеты, HANDOFF и PLAN не изменялись. Этот отчёт в `tasks/` создан по прямому указанию mr.R; остальные файлы `tasks/` не менялись. Коммитов, переключения веток, запуска сервера, браузера и генераций не было.

## Изменённые файлы

- `client/index.html` — разметка меню, вложенных экранов, паузы, настроек, подтверждения выхода, потери связи и тестовой панели; название вкладки и путь к шрифту.
- `client/src/menus.css` — новый файл: пиксельные экраны, фон улицы, портреты, сетка локаций, настройки, баннер, оформление завязки и финала; компоновка для горизонтального телефона.
- `client/src/main.ts` — переходы между экранами, создание/продолжение/вход, выбор и смена героя, пауза, приглашение друга, настройки, обработка потери связи.
- `client/src/session.ts` — контракт GameSession, режим конкретной игры, вызовы функций 18A, тестовые сообщения, токены и переподключение, выход на чистый адрес. Офлайн-снимки обновляются и на паузе, без шага симуляции.
- `client/src/settings.ts` — новый файл: настройки `bc-settings`, проверка сохранённых значений, сохранение, оповещение об изменении и общий вызов тряски с проверкой настройки.
- `client/src/audio.ts` — выключение beep и общего выходного усиления при изменении настройки.
- `client/src/impact.ts` — полные/мягкие/выключенные импакт-эффекты; очистка уже начавшихся эффектов при выключении.
- `client/src/scene.ts` — смена визуального объекта при изменении char того же id, очистка эффектов предыдущего героя, управляемая тряска, баннер restart, выход из финала на чистый адрес.
- `client/src/boss-show.ts` — тряска появления босса учитывает настройки.
- `client/src/story.ts` — GAME_TITLE, стили текстовых экранов и конфетти в палитре игры; пародийное уведомление сохраняет отдельное оформление.
- `client/src/ui.ts` — золотая метка ТЕСТ и подпись манекена по режиму сессии. Уже имеющееся обновление портретов, иконок и цвета по char сохранено.

## Допущения

1. «Живой токен» на стартовом экране — корректный bc-reconnect с временной меткой не старше 60 секунд: это соответствует текущему серверному окну reconnection. Реальную доступность комнаты подтверждает только reconnect. При отказе продолжения токен удаляется, новая комната автоматически не создаётся. Старые записи без временной метки считаются просроченными. Метка и токен обновляются при снимках, пинге открытого соединения, уходе в фон и успешном автоматическом возврате.
2. Тест запускается без текстовой завязки, включая stage 0. Если серверная комната оставляет intro=true, тестовый клиент отправляет introDone после выбора героя. Режим входящего друга всегда берётся из комнаты.
3. Старый ?level=old не влияет на новую игру: обычное прохождение всегда начинается с маршрута. ?stage=N только открывает тестовый экран и выделяет локацию; запуск — нажатием на неё.
4. «Назад» при первоначальном выборе героя возвращает в главное меню через leave и перезагрузку. При смене героя возвращает в паузу. Приглашение друга не снимает уже установленную паузу.
5. Для выхода и повторной игры выбрана разрешённая ТЗ перезагрузка чистого pathname: она также очищает сцены Phaser, таймеры и асинхронные текстовые оверлеи.
