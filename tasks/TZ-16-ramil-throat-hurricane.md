# ТЗ-16: Рамиль, захват за горло, «ураган» с разгоном и броском-«метеором»

Статус: в работе 02.11. Автор: Claude. Исполнитель: Codex (gpt-6.1-sol, high). Отзыв и решение mr.R 02.11 после TZ-15 (`tasks/TZ-15-ramil-grab-ult64.md`).

## Отзыв mr.R и решение
- Карусель за ноги выглядит ужасно: враг плоской доской ездит вокруг Рамиля, который поворачивается в 3D.
- Решено (вариант Claude, одобрен mr.R):
  - **A A, захват за горло** одной рукой: враг висит, ноги болтаются, вторая рука в кармане;
  - **A A A, «ураган»**: держит у груди (малый радиус), 3 оборота с разгоном, размытие, послеобразы, задетые улетают по касательной, как от смерча;
  - **бросок «метеор»**: подкидывает врага вверх за экран, над самой большой гущей растёт тень, враг падает сверху, удар, волна, разлёт.
- **Во время захвата и урагана Рамиль двигается** (mr.R: «должно быть можно»).
- a1 (рывок + нога), ульта, серия B, перекур не меняются.

## Готово до тебя
- Анимации (`anims-data.ts`, часть **временных**, заменю полосами PixelLab без правок кода):
  - `a2` хват за горло (hit = хват);
  - `a2-hold` держит на месте (петля);
  - `a2-walk` идёт с врагом в вытянутой руке (петля);
  - `a3-spin` один оборот на 360° (петля, 1 цикл = 1 оборот);
  - `a3-throw` подкид вверх (hit = отпускание) и возврат.
- Анимации `a3-lift` больше нет, убери её использование.
- Точку руки бери из констант: `GRIP_X` 30, `GRIP_Y` −50 от ступней в пикселях ячейки (рука на уровне плеча). Я подправлю числа по полосам.

## Требования

**R1. Захват (a2).** Цель и условия как в TZ-15 (ближайший не-босс перед ним в `A2_RANGE`, щит не мешает, промах и босс сбрасывают серию, удар по Рамилю отпускает врага). Изменения:
- Захваченный **висит**: стоячий спрайт врага (кадр `hurt` 0 или `idle`), без поворота, приподнят так, что его шея в точке руки. Ноги не касаются пола, тень врага на полу под ним. Лёгкое покачивание (±2 px, ±4°) и болтание при ходьбе. Глубина врага чуть выше Рамиля (он перед рукой).
- Удержание `GRAB_HOLD_MS` 2500 (было 1500: теперь с ним можно идти).
- **Движение во время удержания:** стик двигает Рамиля со скоростью `HOLD_SPEED_MULT` 0.6, анимация `a2-walk`, стоя — `a2-hold`. Разворот по стику разрешён, враг переезжает в руку с другой стороны. A запускает `a3`. Удар по Рамилю отпускает врага (враг падает `down`).
- Слово `ОПА!` при хвате, урон 4.

**R2. «Ураган» (a3).** Только при захвате. 3 оборота с разгоном: `SPIN_TURN_MS [500, 300, 150]`, всего 950 мс. Рамиль неуязвим, ход не прерывается.
- **Движение:** стик двигает со скоростью `SPIN_SPEED_MULT` 0.5, анимация `a3-spin` не прерывается. Кадр `a3-spin` = фаза текущего оборота (на разгоне петля ускоряется вместе с оборотом).
- **Угол** θ: 0 = враг перед Рамилем по взгляду, растёт по обороту.
  - Враг на расстоянии `SPIN_R` 26 от точки руки: x = Рамиль.x + `SPIN_R`·cos θ·facing, y по полосе + сплющенный `SPIN_R`·sin θ·0.3.
  - Передняя половина круга (к камере): враг выше Рамиля по глубине и непрозрачный. Задняя половина: ниже Рамиля, alpha 0.5, большей частью закрыт телом.
- **Центробежный наклон:** спрайт врага отклоняется от вертикали наружу на 30° / 60° / 80° по оборотам (к третьему почти горизонтален). Плавно, без скачков.
- **Эффекты:**
  - кольцо размытия вокруг (2-3 белые дуги эллипса по ходу вращения, alpha растёт с оборотом);
  - послеобразы врага вдоль дуги (2 / 3 / 5 по оборотам, tint белый, alpha 0.4 → 0);
  - пыль вихрем у ног (`ramil-dust` раз в 120 мс, вращать);
  - полосы ветра на 3-м обороте;
  - дым сигареты на время урагана `ramil-smoke-heavy`;
  - лёгкая тряска камеры, растущая с оборотом.
- **Удары:** каждый другой враг в радиусе `SPIN_HIT_R` 56 по x и `ATTACK_BAND` по y, мимо которого проходит захваченный (|угол до врага − θ| < 30° в проекции на x), получает урон `SPIN_DMG` 8, `down`. Отлетает **по касательной** к вращению: по x в сторону движения захваченного в этот момент, 110 px, с небольшим смещением по y полосы. Стоп-кадр 40 мс (только задетый и Рамиль), `ramil-hit` в точке удара, слово по очереди `БУМ!` / `БАХ!` / `ХРЯСЬ!`. Не чаще раза на врага за оборот. Захваченный получает 3 урона за оборот.

**R3. Бросок «метеор» (a3-throw).**
- В кадре hit `a3-throw` захваченный вылетает вверх из руки: за `METEOR_UP_MS` 350 уходит выше верхнего края экрана, вращаясь.
- Цель: центр самой большой гущи (логика из TZ-15). Врагов нет: 200 px вперёд.
- **Тень:** в точке цели на полу тёмный эллипс растёт от 0 до 90x30 за `METEOR_HANG_MS` 450, мигает красным контуром (предупреждение). Слово `ЛОВИ!` при подкиде.
- **Падение:** `METEOR_FALL_MS` 180, враг летит вниз головой с полосами скорости.
- **Удар:**
  - по площади `METEOR_AOE` 90: урон 16, `down`, разлёт наружу 150;
  - брошенный: урон 20, `down`;
  - `impact: 2` (TZ-11), тряска сильная, `ramil-crit` + `ramil-ring` + `ramil-dust` x3 кольцом, трещины на полу (Graphics, гаснут за 600 мс), слово `СТРАЙК!`.
- Рамиль свободен после своей анимации броска (`a3-throw`), падение досчитывается без него. Пока метеор в полёте, его можно атаковать, а `p.combo = 0`.
- Логика полёта в sim, детерминированно: брошенный враг недоступен для ударов до приземления.

**R4. Убрать** карусель за ноги (поворот на 90°, перспективу `scaleX`, дугу броска из TZ-15) и `a3-lift`.
