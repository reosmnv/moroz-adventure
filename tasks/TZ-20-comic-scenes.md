## Цель
Сейчас каждый шаг сюжета (`client/src/story.ts`, `syncStoryView`) показывается затемнённым экраном на весь экран. Нужно, чтобы сюжет разыгрывался в самой игре:
1. Реплики: комикс-облачко над головой говорящего (герой, враг, Милонов, Катя). Затемнения на весь экран для реплик нет.
2. Постановка: во время сцены персонажи выходят, идут, поворачиваются, камера едет к говорящему.
3. Ключевые сцены: Милонов стоит в МФЦ спрайтом, Катя эффектно выходит, телефон и терминал показаны как комикс-кадр рядом с персонажем, а не на весь экран.

Тексты, ID, порядок сцен, звёзды, награда, сетевая логика ведущего (`storyNext` с ключом шага) НЕ меняются. Это смена показа и добавление постановки.

## Неизменные правила
- Тексты только из `shared/src/story-content.ts` по ID. Новых текстов не придумывать. Нужна новая реплика: записать в журнал как вопрос mr.R.
- Кооп: сервер хранит сцену и шаг, продолжает ведущий, ключ шага в команде. Постановка детерминирована в `shared/` и синхронизируется через Schema, а не считается на каждом клиенте по-своему.
- Сюжетная остановка независима от паузы. На входе и выходе сцены сбрасывать зажатые кнопки (уже есть `clearInputs`/`resetControls`).
- Не удалять чужие файлы (`AGENTS.md`, `CODEX-LEAD.md`). Ассеты только добавлять.
- **Выкладка: сначала Pages, потом сервер.** Боевой сервер перезапускать только после того, как `gh run list` показал success для коммита и на сайте новый `index-*.js`. 04.11 сервер обновили раньше сайта, и онлайн завис.

## Контракт данных (общий для этапов 2 и 3, фиксируется на этапе 1)
В `shared/src/story-scenes.ts`:
```ts
export type ActorRef = string; // id героя ('anastasia'|'nadezhda'|'kris'|'ramil') или id актёра сцены ('vat1','omon1','zek1','milonov','katya'...)
| { kind: 'line'; id: StoryTextId; speaker: string; at?: ActorRef }        // at: над кем облачко; по умолчанию сам speaker
| { kind: 'phone'; ids: StoryTextId[]; at?: ActorRef }                     // телефон рядом с этим персонажем
| { kind: 'act'; actor: ActorRef; do: 'spawn' | 'walk' | 'face' | 'exit' | 'pose';
    look?: string; x?: number; y?: number; ms?: number; facing?: 1 | -1; pose?: string }
| { kind: 'act'; actor: 'camera'; do: 'focus'; x: number; ms?: number }
```
- `act` проходит сам (как `state`), без тапа: сервер/LocalSession продвигает шаг, когда истекло `ms` (по умолчанию 0). Несколько `act` подряд с `ms: 0` выполняются в одном тике (параллельно), последний с `ms` задаёт ожидание.
- Актёры живут только в сцене: `world.actors: Record<string, Actor>`, `Actor = { id, look, x, y, tx, ty, facing, anim, speed }`. После конца сцены удаляются, если сцена не оставила их явно (флаг `keep` у spawn для Милонова до конца сцены `sender`).
- Герой как актёр: `act` с id героя двигает его игрока, если он есть в мире; если героя никто не выбрал, шаг пропускается.
- Камера: `world.storyCamX?: number` (центр), клиент плавно ведёт камеру туда во время сцены и отдаёт обратно после.
- Облачко над героем, которого нет в мире: облачко у края экрана с маленьким портретом (`portrait()` из `story.ts`).
- Вид актёров (`look`): любой `kind` из `ENEMY_ANIMS`, `'katya'` (`KATYA_ANIMS`), `'milonov'` (статичный `client/public/ui/story/milonov-pl.png` или его анимация, если появится).
