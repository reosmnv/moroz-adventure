# TZ-19: сценарий v2 в игру (тексты, пуши реестра, подсказки, живые реплики, финал у окна)

Цель: внести в игру сценарий из `SCENARIO.md` целиком (кроме строк с пометкой [а], генерации не нужны). **Тексты бери дословно из `SCENARIO.md` по ID**, не переписывай. Если текст не влезает в лимит из таблицы «Носители и лимиты», не сокращай сам, а перечисли в отчёте.

Все игровые тексты, которые меняются в этом ТЗ, собрать так, чтобы mr.R мог править их в одном-двух местах: `client/src/story.ts` (объект `STORY`, клиентские тексты: завязка, перекличка, пуши, подсказки, финал, служебные) и `shared/src/lines.ts` (новый файл: реплики, которые порождает sim: события, ульта, ответы боссам, последние слова боссов). Вставки врагов остаются в `shared/src/intros.ts`, карточки и вывески в `shared/src/route-data.ts`.

Архитектура как в `CLAUDE.md`: реплики, которые должны видеть все игроки одинаково, порождает sim событием `taunt` (детерминированно, случайность только через `world.seed`). Пуши, подсказки, экраны считаются на клиенте по снимкам и событиям.

## R3. Пуши реестра [к]
- Плашка сверху по центру в стиле уведомления завязки (белая, синяя полоска сверху, системный шрифт, это пародия), мелкая строка «Реестр» и текст. Висит 3 с, бой не останавливает, не перекрывает панели героев и кнопку паузы (при нехватке ширины ужимается). Касание по ней закрывает. Видят все игроки одновременно (триггер по снимку, не по локальному таймеру).
- Триггеры: `push.1` после последнего боя улицы; `push.2` при выходе со двора (переход стадии); `push.3` в вагоне после первого боя; `push.4` через 2 с после поражения Пиздулиной (после её последней реплики); `push.5` после первого боя Сити. Каждый пуш один раз за прохождение (повтор боя после поражения не повторяет).

## R4. Подсказки обучения [к]
- На каждом телефоне свои, только в «Новой игре» (не в тест-режиме), один раз за прохождение, гаснут после действия (или через 8 с для `tip.ult`):
  - `tip.move`: у стика, со старта улицы, гаснет после 1 с движения. На устройстве без тача текст «СТРЕЛКИ».
  - `tip.hit`: у кнопки удара, когда ближайший враг ближе 200 px; гаснет после 3 ударов.
  - `tip.ult`: у кнопки ульты, когда шкала впервые полна; гаснет при нажатии.
  - `tip.smoke`: только Рамиль, у кнопки перекура, после первого боя, если ни разу не держал; гаснет при удержании.
- Подсказка: мигающий текст 8px золотом со стрелкой к элементу, не перекрывает сам элемент.
