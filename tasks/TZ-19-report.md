# Отчёт TZ-19

Работа в текущей ветке `tz-19`, без коммитов, переключения веток, запусков сервера и генераций. Отчёт в `tasks/` создан по прямому указанию mr.R; остальные документы Claude не менялись. Существующие неотслеживаемые ассеты не трогал.

## Файлы и тексты для правки

- `client/src/story.ts`: STORY, тексты меню, роли, завязка, перекличка, пуши, подсказки, служебные сообщения, карточка последнего боя, финал; печать диалога, портреты и кадр Kris.
- `shared/src/lines.ts` (новый): готовность ульты, реплики событий, обращения, ответы боссам, последние слова, подсказка поцелуя.
- `shared/src/intros.ts`: подписи и реплики вставок.
- `shared/src/route-data.ts`: карточки и вывески, координаты; переносы строк без сокращения слов.
- `shared/src/sim.ts`: новые насмешки, сюжетные события taunt, задержки последних слов, отметки пушей.
- `shared/src/index.ts`: экспорт lines.
- `server/src/GameRoom.ts`, `client/src/session.ts`: время симуляции и отметки пушей в снимках; существующий pausedBy доступен в снимке.
- `client/src/main.ts`: экран созданной комнаты до выбора героя, роли, пауза, выход, ошибки подключения и копирование ссылки.
- `client/src/ui.ts`: пуши, обучение, счётчик боя, карточка охраны окна.
- `client/src/scene.ts`: метка своего героя, поезд, рестарт, слово при поцелуе босса, снимок Пиздулиной.
- `client/src/menus.css`: роли, прокрутка финала, штамп, размеры служебных экранов.
- `server/src/sim-test.ts`: 26 дополнительных проверок TZ19.
- `tasks/TZ-19-report.md`: этот отчёт.

## Допущения

- При падении выбирается один из двух типов реакции: сам упавший либо живой друг. Они конкурируют за общий кулдаун; две реплики подряд не выдаются. В одиночку говорит упавший.
- «Настя, если она в команде» для ответа боссу трактуется как живая подключённая Настя.
- Для одинаковых пушей и поддержки позднего входа мир хранит только пять временных отметок; клиент по снимку решает видимость/содержимое плашки. При паузе время симуляции и уведомления стоят вместе с миром.
- Три удара обучения считаются по нажатиям кнопки удара; попадать по врагу для снятия подсказки не требуется.
- Последние слова и задержка пуша используют время sim, включая штатное замедление при поражении босса.
- Из вариантов SCENARIO взяты первая кнопка intro.btn «В смысле нет?!» и fin.body А; подпись «Надя, Kris, Рамиль».

3. Для вывесок добавлен межстрочный интервал; размер новых вывесок увеличен до 8 и более.
4. Реклама в вагоне перенесена на x=1080, y=105.
5. Подсказка движения поднята над стиком; остальные подсказки остаются у элементов управления. Их положение относительно героев и кнопок требует повторной проверки на скриншотах.
