## Правка 1

Предварительно выставленные враги теперь размещаются общей функцией `placeStoryFormation`: каждый следующий сдвинут вправо на 24 px, высота меняется с шагом 24 px и ограничивается полосой ходьбы. Для боссов и живой свиты строй выставляется один раз при подготовке сцены, после диалога те же сущности остаются на тех же координатах. Герои получают ближайший край строя, враги смотрят влево.

В `server/src/story-test.ts` добавлена попарная проверка `|dx| >= 18 || |dy| >= 22` для всех шести сцен первой волны и трёх сцен боссов. Существующая проверка сохраняет id и координаты до конца диалога. Ожидания координат в сетевом тесте скорректированы под новый строй.

Проверки: `npx tsc -p tsconfig.json --noEmit`, `node --import tsx server/src/sim-test.ts`, `npm run test:story`, `npm run test:lane`, `node --import tsx server/src/boss-crowd-test.ts`, в `client/` `node ../node_modules/vite/bin/vite.js build`: все exit 0. Логи: `/tmp/tz22-fix1-{tsc,sim,story,lane,boss,build}.log`. Браузер и test:net по указанию не запускались; визуальное расстояние между крупными спрайтами требует приёмки.

## Правка 2

Причина: завершающий проход `stepCore` вызывал `clampEnemyX` для всех врагов, включая ожидающих сцены. Пока арена не заперта, эта функция ограничивает координату диапазоном ±300 от героев. Поэтому ещё при подходе весь правый край строя прижимался к `focusX + 300`. Изолированный тест сразу после создания мира этот проход не выполнял и дефект пропустил.

Ожидающие сцену враги исключены из заключительного ограничения координат. После диалога они первые 600 мс синхронно идут влево со скоростью 35 px/с, сохраняя интервалы; затем включается обычное поведение боя. Это намеренная задержка атак на 600 мс. Замок встречи и сами сущности сохраняются.

Добавлен тест с одним героем: обычная ходьба через `step` и `startStoryForWorld`, затем проверка шести врагов до диалога, после него и через 600 мс. Также расширен прогон кампании с четырьмя героями: street_vat, arch, vestibule, wagon, mayak, city, shaman, pizdulina и katya проверяются по тем же трём моментам, включая свиту боссов. Предыдущие бои ускорены тестовым обнулением HP. Проверяются попарные расстояния, сохранение id и координат и отсутствие скачка за первые 600 мс.

Проверки: `npx tsc -p tsconfig.json --noEmit`, `node --import tsx server/src/sim-test.ts`, `npm run test:story`, `npm run test:lane`, `node --import tsx server/src/boss-crowd-test.ts`, в `client/` `node ../node_modules/vite/bin/vite.js build`, `git diff --check`: exit 0. Playwright и test:net не запускались, визуальная приёмка остаётся открытой.
