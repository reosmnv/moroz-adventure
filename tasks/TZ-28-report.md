## Обход для тестов и изоляция релиза

Флаг TEST_TOOLS константный, без переменных окружения и URL-переключателей. Входы LocalSession/OnlineSession и производственный GameRoom используют этот флаг. Чистые функции `testStoryScene`/`testStoryStrict` (`shared/src/story-state.ts:118,173`) теперь, как остальные test-функции sim, требуют явно созданный `world.testTools=true`. Автотесты создают такие миры напрямую; пользовательский запрос релизной комнаты создать их не может.

`server/src/sim-test.ts:580,713,885` и `server/src/lane-test.ts:83` явно отмечают сцены завершёнными там, где проверяется только бой/переход без проигрывателя сюжета. Story-test проверяет настоящее прохождение сцен.

Старый net-test требует тестовые команды, поэтому добавлена отдельная точка запуска `server/src/net-test-server.ts:1`. Только её подкласс переопределяет защищённый `GameRoom.testToolsEnabled()`. Сервер фикстуры слушает фиксированный `127.0.0.1:2568`; production `server/src/index.ts` импортирует обычный GameRoom и не импортирует фикстуру. `server/src/net-test.ts:6` принимает только адрес этой фикстуры, чтобы тесты не попали на боевой :2567. Фикстура не запускалась, её сетевой прогон остаётся Claude.
