# Шаблон персонажа (собран по Анастасии, 29.10.2026)

Копировать в `characters/<id>.md` и заполнять сверху вниз. В скобках образец Анастасии.
Ссылки: карточка `characters/anastasia.md`, генерация `../PIXELLAB.md`.

## 0. Решения до старта (блокируют всё остальное)
- [ ] id латиницей (`anastasia`) и имя в игре (Анастасия)
- [ ] Две формы или одна (Prime + Ultimate). Две формы = вдвое больше анимаций
- [ ] Асимметричный наряд? Да = east и west генерируются отдельно (x2 к анимациям). Нет = west через flipX
- [ ] Боевой стиль, задающий все удары (тайский бокс)
- [ ] Что делает ульта (превращение на N с, сильнее и быстрее) и есть ли вторая (снежная буря, общая шкала)

## 1. Личность
- [ ] Кто в жизни, профессия, хобби (саунд-продюсер, певица, тайский бокс)
- [ ] Манера речи (голос ведущей; на нервах ругается)

## 2. Внешность (промпт для PixelLab)
- [ ] Форма 1: волосы, верх, низ, обувь, отличительные детали (джинсы, топ пополам белый/чёрный, разные кроссовки)
- [ ] Форма 2, если есть (хвост, чёрный топ, красные шорты, обмотки красная и бирюзовая, босиком)
- [ ] Татуировки, аксессуары
- [ ] Цвет вспышки превращения, называть явно в тексте («cyan and white energy»)
- [ ] Референс: фото не работает как картинка, только как описание словами

## 5. Анимации на одну форму (x2 направления east/west)
| Анимация | Способ в PixelLab (из опыта) |
|---|---|
| idle | skeleton-v3 `fight-stance-idle-8-frames` |
| walk | skeleton-v3 `walk` |
| dash (бег) | шаблон running / full-sprint |
| 3 удара серии A | руками: поза `edit_image` + v3 вход/выход; ногами: skeleton-v3 шаблон + переход `-pre` |
| 3 сильных удара B | то же; акробатика через pixminimax 16 кадров |
| hurt | skeleton-v3 `taking-punch` |
| fall | skeleton-v3 `falling-back-death` |
| getup | skeleton-v3 `getting-up` |
| transform-up / transform-down | v3 12 кадров, стойка А → стойка Б, цвет вспышки в тексте |
| static (1 кадр) | первый кадр idle |
| taunt | пока нет, позже |
Итого у Анастасии 13 анимаций на форму, 26 полос на форму, 52 полосы всего.
